## Project Purpose

MedNexus_Intelligence™ is a medical report intelligence dashboard built for portfolio, academic, and professional demonstration. It provides a complete workflow for PDF report upload, backend processing, structured risk interpretation, preview, and report download.

## Deployment Identity

The project is designed as a full-stack application:

- FastAPI backend for upload, processing, health checks and report delivery.
- Next.js frontend for the dashboard and user workflow.
- Optional external AI pipeline integration through environment variables.
- Safe demo fallback for portfolio deployment when the external AI service is not configured.
